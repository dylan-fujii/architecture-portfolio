# Dylan Fujii Architecture Portfolio

This is an independent static website. It has no provider branding, generated imagery, or external runtime dependencies.

## Source and organization

`projects.js` is the content source for titles, source text, dates, tool lists, asset sequencing, and portfolio order. Project order follows the supplied portfolios, except that The Joinery is intentionally featured first as the ACSA Timber in the City award-winning work.

The three original portfolio PDFs are preserved in `assets/pdfs/` and remain available on each project page. Individual website assets in `assets/images/` are direct PDF images where available, or high-resolution source-board crops when the PDF presents a composed board. Composite boards are retained when their labels, graphic scale, or relationships are integral to the work.

Open `index.html` locally to review. Publish the `independent-portfolio` folder to any neutral static host when ready.
